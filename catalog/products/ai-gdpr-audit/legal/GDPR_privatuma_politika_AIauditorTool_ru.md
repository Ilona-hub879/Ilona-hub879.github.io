**Последнее изменение: 18 сентября 2026 г.**

Настоящая политика конфиденциальности (далее — Политика) объясняет, как самозанятое лицо Ilona Samoviča (рег. № LV07098010209, адрес: Gaismas ielā 6, Daugavpils, Latvija) (далее — Контролёр) обрабатывает персональные данные пользователей в приложении AI GDPR Audit tool (далее — Приложение).

Приложение — автоматизированный инструмент, использующий технологии искусственного интеллекта (ИИ) для первичного экспресс-анализа документов с максимально полным скринингом (предварительным аудитом). В основе анализа лежит большая языковая модель, обученная распознавать в юридических текстах шаблоны, термины и структуры, связанные с GDPR и другими актами о защите данных. Приложение не является поставщиком юридических услуг, не заменяет квалифицированного юриста или адвоката, а предоставляемые им рекомендации носят исключительно информационный характер. **Окончательное решение о соответствии документов и** **внесении исправлений всегда принимает сам Пользователь (человек).**

**1\. Общие положения**

1.1. Инфраструктуру Приложения обеспечивают технологии Next.js (Vercel) и Python/FastAPI, а анализ данных — сервисы API GeminiAI (Google Cloud).

1.2. Приложение предназначено только для совершеннолетних лиц (достигших 18 лет) в рамках хозяйственной, профессиональной деятельности или личных интересов. Используя этот инструмент, Вы подтверждаете своё совершеннолетие. Приложение **не проверяет** возраст Пользователя или статус предпринимателя; Пользователь подтверждает это, продолжая пользоваться сервисом.

1.3. **Бесплатная демонстрация:** Приложение предлагается как **некоммерческая бесплатная демонстрация**, пока хватает мощности ИИ. **Нет оплаты, подписки и банковских карт.** Полный анализ бесплатно с лимитами fair use (см. раздел 3).  
1.4. Пользователь несёт ответственность за содержание загружаемого документа и обязуется не загружать документы, содержащие персональные данные особых категорий (например, данные о здоровье, расе, этническом происхождении, политических взглядах, религиозных убеждениях) или данные о судимости, если у Пользователя нет законного основания для передачи таких данных на анализ. Приложение не предназначено для обработки таких данных, и Контролёр не несёт ответственности за их случайную обработку.  
Пользователь обязуется не загружать документы, содержащие национальные идентификаторы, например персональный код, без особой необходимости и законного основания.

**2\. Обрабатываемые данные и цели**

Контролёр обрабатывает только минимально необходимые данные для обеспечения функциональности Приложения:

- **2.1. Содержание загруженного документа:** обрабатывается исключительно для проведения автоматического анализа текста и подготовки предварительного отчёта GDPR-аудита. **Ограничения по документам:** в одном аудите принимается **PDF или DOCX**, не более **15 (пятнадцати) страниц** и размер файла **1 MB**, если в Приложении не указано иное.
- **2.2. Контактная информация:** адрес электронной почты обрабатывается для сервисных уведомлений (включая _magic link_ на отчёт).
- **2.3. Метаданные сессии:** session_id, email, технический статус сессии и метки времени. Значения вроде _pending/paid_ — технические метки доступа к отчёту, **не** подтверждение оплаты.
- **2.4. Данные безопасности (предотвращение злоупотреблений):** IP-адрес, идентификаторы браузера (включая цифровой отпечаток — _fingerprint_), для предотвращения злоупотребления сервисом, контроля лимитов Демо-режима и частоты API-запросов. **Аналитика маркетинга продукта или отслеживающие рекламные cookie в этом Приложении не используются.**
- **2.5. Счётчики fair use:** хеши email, IP и fingerprint только для дневных лимитов (п. 3.2).

**3\. Бесплатная демонстрация**

3.1. Приложение даёт **полные AI GDPR-аудиты без оплаты** как образовательную демонстрацию, пока хватает мощности ИИ. Это не платная юридическая услуга.  
3.2. До **2 (двух) полных AI-аудитов в день** на пользователя (email, IP, fingerprint). После лимита — ждите следующий день; **платного обхода нет**.

**4\. Хранение данных, безопасность и принцип «Zero-Retention»**

4.1. **Немедленное удаление документов (Zero-Retention):** загруженные документы не хранятся постоянно и не записываются в базы данных Контролёра как долгосрочные записи. Содержание документа обрабатывается для анализа; частная временная копия в зашифрованном объектном хранилище может существовать только до завершения анализа или до истечения срока незавершённой сессии (см. 4.3.). После успешного анализа временный файл удаляется немедленно.  
Оригинальный загруженный файл не хранится в базе данных Контролёра как полная копия документа. Однако **результат анализа** (структурированный отчёт AI-аудита, который может включать цитаты фрагментов документа или перефразировки) хранится как **часть метаданных сессии** только столько, сколько необходимо для доступа в соответствии с пунктом 4.3., после чего удаляется или анонимизируется в соответствии с техническими правилами.  
4.2. **Запрет на обучение моделей ИИ:** содержание документов, загруженных Пользователем, и содержащиеся в них данные **ни при каких** **обстоятельствах не используются** для обучения или улучшения моделей искусственного интеллекта (включая Google Gemini). Контролёр передаёт содержание только для вызовов API анализа в соответствии с условиями сервисов Google Cloud / Gemini и **не использует** документы Пользователя для обучения собственных моделей ИИ.

4.3. **Сроки доступа и хранения:** Контролёр хранит минимальные метаданные сессии и **результат анализа** (включая **analysis_result** в JSON, имя файла, язык и код юрисдикции), чтобы обеспечить доступ к отчёту по уникальной ссылке **до 45 (сорока пяти) дней** после генерации и для технической поддержки. По истечении срока ссылка прекращает действовать, результаты удаляются. Незавершённые сессии удаляются не позднее **7 (семи) дней**. Рекомендуется сохранить локальную копию отчёта.  
4.4. **Сводка сроков хранения**

- **Счётчики лимитов демо** (неидентифицирующие hash IP, email, fingerprint): до **14 (четырнадцати) дней**, затем удаляются.
- **Незавершённые сессии** (статус _pending_): до **7 (семи) дней**, затем удаляются.
- **Отчёт** (**analysis_result**, доступ по magic link): до **45 (сорока пяти) дней**, затем удаляется из активного хранилища; минимальные метаданные (email, имя файла) могут храниться дольше только для требований безопасности или законных претензий.
